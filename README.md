# 文件磁铁 v2.0

从一个或多个文件夹（以及它们的所有子文件夹）里，按条件锁定需要的文件，再拷贝、移动、打包到指定位置。
“拷贝各机位某个时段的照片”只是其中一个常用场景；按文件名、编号、名单、时间、类型、作者、相机、文件内容等都可以组合筛选。

所有操作都在本机完成，不上传任何文件。网页是操作界面，后台由随包附带的 Python 运行。

---

## 一、启动

| 系统 | 怎么启动 | 需要安装什么 |
| --- | --- | --- |
| Windows 10 / 11 | 解压后双击 **start-windows.bat** | 不需要（已附带官方 Python） |
| macOS | 解压后双击 **start-mac.command**（第一次请右键 → 打开） | 系统提示安装“命令行开发者工具”时点“安装”，只需一次 |
| Linux | 运行 `./start-linux.sh` | Python 3.8 以上 |

- 一定要**先把 zip 整个解压**，不要在压缩包里直接双击。
- Windows 建议解压前先在 zip 上右键 → 属性 → 勾选“解除锁定”，可以避免安全提示。
- 启动后会出现一个黑色窗口，并自动打开浏览器。**使用期间不要关闭黑色窗口**；点页面右上角“退出”或关掉黑窗口即结束。
- 如果附带的 Python 被公司电脑策略禁止运行，会自动改用 `legacy/` 里的旧版（只用 Windows 自带的 PowerShell，功能较少）。

## 三、锁定文件的四种方式（可以混用）

1. **一句话**：在最上面输入需求，点“理解”。工具会给出它的理解、拆成的条件，以及没听懂的词（红色标出）。确认后点“用这些条件替换”或“追加”。
   - 默认用本地解析：离线、免费、即时。
   - 可在“设置”里接入大模型（Claude，或 DeepSeek、通义千问、Kimi、本地 Ollama 等兼容 OpenAI 格式的接口），处理更复杂的说法。只发送这句话、字段说明、文件夹名和少量文件名样本，**不发送文件内容**。
2. **条件积木**：选字段 → 选条件 → 填值。支持“全部满足 / 满足任一 / 排除”和嵌套条件组。每条条件右侧的“卡掉 N”表示只因为这一条被排除的文件数，哪条太严一眼可见。
3. **挑样例**：在看片台点“挑样例”，圈出 3–5 个想要的文件，点“根据样例推断规则”，工具会列出它们的共同点（文件名格式、时间段、类型、所在文件夹、相机……）供勾选。
4. **按名单查找**：粘贴客户给的编号或文件名，或导入 Excel（.xlsx）/ CSV / TXT。可选择按“主文件名相同 / 编号相同 / 文件名包含”匹配，结果会列出找到、找到多个、未找到的项，并可复制未找到的清单。名单里的其他列（如“客户”）可以直接用作文件夹名。

### 可用于筛选的信息

| 分类 | 字段 |
| --- | --- |
| 文件名 | 文件名、主文件名、扩展名、文件类型（照片 / RAW / 视频 / 文档……）、文件名中的编号、文件名中的日期 |
| 位置 | 一级文件夹、二级文件夹、所在文件夹、路径中任一文件夹、相对路径、所在层级、来源文件夹 |
| 时间与大小 | 大小、修改时间、创建时间 |
| 照片与视频 | 拍摄时间（照片 EXIF、视频文件内时间）、相机、机身序列号、镜头、照片作者、星级（含同名 .xmp） |
| 人员 | 创建人（任意来源）、文档作者、最后修改者、文件所有者 |
| 内容 | 文档标题、文件内容（txt、csv、Word、Excel、PPT；PDF 尽力而为） |

时间条件支持：每天的时段（可跨午夜）、某一天、今天 / 昨天 / 本周 / 上周 / 本月……、最近 N 分钟/小时/天、具体起止时间、早于 / 晚于。

> **关于“创建时间”**：照片从存储卡拷到电脑后，Windows 上的创建时间通常会变成**拷贝的时刻**。如果按创建时间筛不到或筛错，看一下“时间分布”图里文件实际集中在什么时段，再改用“拍摄时间”或“修改时间”。“常用场景”里两种都有现成的。

## 四、放到哪里、怎么处理

- **子文件夹怎么建**（点下方变量即可插入）：

| 模板 | 效果 |
| --- | --- |
| `{一级文件夹}/{子目录}` | 每个机位一个文件夹，保留机位内部的原有层级（默认） |
| `{一级文件夹}` | 每个机位一个文件夹，内部不分层 |
| （留空） | 全部放进目标文件夹本身 |
| `{相对目录}` | 完整保留来源里的目录结构 |
| `{拍摄日期:yyyy-MM}/{拍摄日期:yyyy-MM-dd}` | 按拍摄月份、日期归档 |
| `{相机}`、`{类型}`、`{扩展名}`、`{作者}` | 按相机、文件类型、扩展名、作者分开 |
| `{名单.客户}` | 按名单里“客户”列分开 |

  重命名（可选），例如 `{一级文件夹}_{文件名}`，可避免全部放在一起时重名。
- **处理方式**：拷贝、移动、链接（不占空间，需同一磁盘）、打包成 zip、只导出 CSV 清单。
- **重名时**：自动改名（完全相同的文件跳过）、跳过、源文件较新时覆盖、覆盖。覆盖前会先备份原文件，可撤销。
- **内容完全相同的文件只保留一个**：按文件内容比对，适合多张卡里有重复导入的情况。
- **持续监视新文件**：拍摄现场把相机照片实时导入来源文件夹时，勾选后每隔几秒自动把新照片按规则拷走；写入未完成的文件会等下一轮再处理。

### 撤销

每次执行都会留下记录（右上角“执行记录”）。点“撤销”会：删除这次拷贝出的文件（之后被改动过的会保留），把移动的文件移回原处，从备份恢复被覆盖的文件，删掉这次新建的空文件夹。
每次执行的明细另存为 CSV，在工具文件夹的 `logs` 里。

## 五、方案与常用场景

- 左侧“常用场景”是现成的模板，点一下即可套用（会保留你的来源和目标文件夹）。
- “我的方案”可以把当前全部设置保存下来，下次一键载入；也可以导出成文件发给别的电脑。

### 不打开界面，定时自动执行

先在界面里保存方案（或导出成文件），然后：

```
Windows：runtime\windows-x64\python.exe engine\server.py --run "presets\方案名.json"
macOS / Linux：python3 engine/server.py --run "presets/方案名.json"
```

加 `--preview` 只列出匹配结果，不执行。退出码：0 成功，1 出错，2 部分文件失败。
Windows 可在“任务计划程序”里新建任务，“操作”填上面的命令、“起始于”填工具文件夹。

## 六、常见问题

**页面显示“未连接”**：请通过启动脚本打开，不要直接双击 `app/index.html`；黑色窗口被关掉了就重新双击启动脚本。

**端口被占用**：会自动换一个空闲端口，无需处理。

**看不到缩略图**：JPG 和大多数 RAW（CR2、CR3、NEF、ARW、DNG、RAF、RW2……）会读取文件内嵌的预览图；HEIC 只有 Safari 能显示；视频、文档显示类型标签，点开可以播放视频、查看 PDF。

**目标文件夹不能放在来源文件夹里面**：避免把拷贝出的文件再次当作素材处理。

**大模型连不上**：在“设置”里点“测试连接”看具体原因。公司内网或保密环境请使用本地解析，其余功能不受影响。

## 七、文件夹说明（给维护人员）

```
start-windows.bat / start-mac.command / start-linux.sh   启动脚本
app/            界面（index.html、app.css、app.js）
engine/         后台（server.py 与 mcct/ 模块，只用 Python 标准库，兼容 Python 3.8+）
  mcct/index.py    扫描来源、建立索引        mcct/rules.py   字段、条件、查询
  mcct/meta.py     EXIF / RAW / Office / PDF / 所有者 / 正文
  mcct/plan.py     路径模板、重名处理        mcct/jobs.py    执行、监视、撤销
  mcct/nl.py       本地中文解析              mcct/llm.py     大模型（可选）
  mcct/infer.py    以例选文                  mcct/listfile.py 名单解析
runtime/windows-x64/   官方 Windows 嵌入式 Python 3.13（已核对 Python 软件基金会数字签名）
templates/      常用场景模板（可自行增加 .json）
presets/        保存的方案
legacy/         旧版 PowerShell 应急版
logs/           执行明细与撤销记录（首次执行后生成）
settings.json   设置（含大模型 API Key，首次保存设置后生成）
```

**增加一个筛选字段**：在 `mcct/rules.py` 的 `FIELDS` 里登记，并在 `get_value()` 里实现取值；界面会自动出现。若希望一句话也能识别，在 `mcct/nl.py` 里加一个识别步骤。
