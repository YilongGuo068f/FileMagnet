使用说明
  1. 填写源目录（放各机位文件夹的大文件夹）和目标目录。
  2. 按需调整筛选条件。时间默认按“创建时间”，每天 11:38～11:41。
  3. 点“先预览匹配结果”，在下方核对每个机位的文件和时间。
  4. 确认无误后点“开始执行”。每次运行的明细都会保存成 CSV，放在工具目录的 logs 文件夹。
  5. 常用设置可“保存方案”，下次直接载入。
